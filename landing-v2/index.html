03Deterministic failover

The request that still succeeds.

A primary provider fails. Tanvelo follows your policy, moves to the next model, and returns one clean response. The caller never sees the seam.

Without a fallback, this request is a 500 in your product.

04Quickstart

Change one line.

Keep the SDK, the tooling, the evals. Point base_url at Tanvelo and route to any supported model.

  1. 01Create a gateway key
  2. 02Set the base URL
  3. 03Ship the request
quickstart.py 
from openai import OpenAI

client = OpenAI(
    base_url="https://api.tanvelo.dev/v1",
    api_key="tv_live_••••••••",
)

# any model, one contract
stream = client.chat.completions.create(
    model="claude-3-5-sonnet",
    messages=[{
        "role": "user",
        "content": "Ship it.",
    }],
    stream=True,
)
